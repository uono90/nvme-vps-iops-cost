## 哪些负载值得为 NVMe 付钱

数据库、容器、CI runner 这三类负载最能体现差别，其余大多数场景感知不明显。

先看硬数字。NVMe 走 PCIe 通道，顺序读写能到 4–6 GB/s，SATA SSD 只有 500–600 MB/s，差 8–10 倍。但更关键的差距在随机 I/O：NVMe 能跑出 50 万 IOPS 以上，SATA SSD 大约 8–10 万。数据库查询、消息队列、Redis 持久化这类以随机小文件读写为主的负载，看的就是后一个数字。落到日常操作上，NVMe 机器拉 Docker 镜像快 2–3 倍，git clone 能省 40–60% 的时间。

反过来，WordPress 纯静态缓存站、备份归档、只挂一个 socks 代理的机器，瓶颈都不在磁盘随机性能上，为 NVMe 多付的钱花在了用不到的地方。
